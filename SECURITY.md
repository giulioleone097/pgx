# Reporting vulnerabilities

Use [GitHub private vulnerability reporting](https://github.com/pgrundev/pgx/security/advisories/new).
If the form is unavailable, contact the repository owner through their GitHub
profile and request a private channel before sending exploit details. Do not
post credentials or unpublished exploits in public issues.

Include the affected version and platform, minimal reproduction, impact, and
any proposed fix. There is no published response-time guarantee.

PGX is beta software for disposable development and test databases. Reproduce
against the latest release or main; older beta releases do not have a separate
security backport promise. Verify release artifacts using the installer's
provenance checks.
